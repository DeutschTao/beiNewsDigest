## 〇、本版本与 v1 的差异总览

v2 是完全推倒重写的版本。下表列出与 v1 的核心差异，帮助理解为什么需要重写、新方案如何解决问题。

| 维度 | v1（旧） | v2（新） |
|------|---------|---------|
| **数据源** | 9 个 RSS 源，其中 Reuters 已 404、CNN 抓不到，实际可用 5 个 | 5 个稳定源，其中 4 个自研爬虫（BBC/CNN/Al Jazeera/AP），1 个 RSS 降级（Reuters → Google News RSS） |
| **抓取方式** | 统一 RSS / feedparser | **双通道**：预设源走专用 Crawler；自定义源按用户选择走 RSS 或通用 HTML 爬虫 |
| **数据模型** | 6 张表（raw_news / processed_news / news_atoms / daily_digest / digest_news 等），带 AI 摘要因果链 | **3 张核心表**：news_sources / news_articles（列表）/ news_contents（按需详情正文） |
| **AI 摘要** | OpenAI / Ollama 双方案 + 3 种 atom（text/quote/wiki），耗 token、慢、依赖外部 | **完全移除**，不再依赖任何大模型 |
| **首页内容** | 每日精选 8 条 Digest（手动构造） | 按来源分组，每个源取 Top 3，共 15 条左右 |
| **详情页** | 先展示 RSS 摘要，"AI 智能分析"按钮跳到 Atoms 页 | 直接展示抓到的原文，无 AI 分析入口 |
| **图片处理** | 服务端代理（防盗链） | 保留服务端代理，但优先级降低（因为很多图源已有公开访问） |
| **爬虫调度** | 单一 cron（每天 6:00 抓、6:30 处理、7:00 生成 Digest） | **分时段调度**：早高峰 30 分钟、日间 1 小时、晚高峰 30 分钟、夜间 3 小时 |
| **去重策略** | guid → content_url 兜底 | `sha1(source_code + content_url)` 作主键 + 列表内 `position` 字段 |
| **推送** | UI 有，后端未实现 | UI 占位，后端**本版本不实现** |
| **数据保留** | 7 天硬编码 | 7 天，**可配置** |
| **API 前缀** | `/api/*` | **`/api/v2/*`**（域名复用，白名单不动） |
| **部署** | 阿里云 + 代理 | 复用同一个阿里云实例与代理 |

> **注**：v1 仍然保留在 `backend/` 目录，作为历史参考。新代码全部在 `version2/backend/`。

## 一、项目概述

### 1.1 项目定位

后端服务为 Bei News Digest 小程序提供数据支撑，负责：
- 新闻抓取（5 个预设源 + 用户自定义源）
- 数据持久化（SQLite）
- 新闻源管理（CRUD + 连通性检测）
- API 接口暴露（5 个页面所需的所有数据）

不再负责：
- ~~AI 摘要生成~~
- ~~Digest 编排 / 每日精选~~
- ~~Web 推送通知~~

### 1.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **语言** | Python 3.10+ | 开发语言 |
| **框架** | FastAPI | Web 框架，继承 v1 |
| **数据库** | SQLite 3 + WAL | 数据存储，沿用 v1 |
| **ORM** | SQLAlchemy 2.0 | 数据库操作 |
| **HTML 解析** | BeautifulSoup4 + lxml | 通用 HTML 解析（新增） |
| **RSS 解析** | feedparser | RSS 源（自定义源可能用） |
| **HTTP 客户端** | httpx | 异步 HTTP（可走代理） |
| **调度** | APScheduler | 基于 v1，扩展为分时段 |
| **配置** | PyYAML | 配置文件读取 |
| **数据验证** | Pydantic v2 | Schema |

### 1.3 第三方服务依赖

|------|------|---------|
| 阿里云 ECS 代理（`127.0.0.1:7890`） | 访问 BBC/CNN/AP/Al Jazeera，避免被源站 ban | **必需**（v1 已验证） |
| Google News RSS | Reuters 降级方案 | 必需 |
| ~~OpenAI / Ollama~~ | ~~AI 摘要~~ | **已移除** |

## 四、数据模型

从 v1 的 6 张表精简到 **3 张核心表**。

### 4.1 表结构总览

```
┌──────────────┐         ┌──────────────────┐        ┌──────────────────┐
│ news_sources │ 1     * │  news_articles   │ 1   0..1│  news_contents   │
│  新闻源      │─────────│  新闻列表        │────────│  详情正文（按需）│
│              │         │  (首页/列表数据)  │        │                  │
└──────────────┘         └──────────────────┘        └──────────────────┘
```

### 4.2 news_sources（新闻源）

```sql
CREATE TABLE news_sources (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  code            TEXT NOT NULL UNIQUE,         -- bbc / cnn / aljazeera / ap / reuters / custom_xxx
  name            TEXT NOT NULL,                 -- 显示名称
  source_type     TEXT NOT NULL,                 -- 'crawler' | 'rss'
  homepage_url    TEXT,                          -- 爬虫源首页 / RSS 源首页（用于详情页 base）
  rss_url         TEXT,                          -- 仅 RSS 源用到
  category        TEXT DEFAULT 'world',
  crawler_class   TEXT,                          -- 爬虫源指向哪个类，如 'BBCCrawler'
  is_enabled      INTEGER DEFAULT 1,             -- 是否启用（前端开关）
  is_recommended  INTEGER DEFAULT 0,             -- 是否预设源（不可删除）
  display_order   INTEGER DEFAULT 0,
  created_at      TEXT,
  updated_at      TEXT
);

CREATE INDEX idx_sources_enabled ON news_sources(is_enabled);
```

**关键字段说明**：

- `source_type`：决定数据来源走哪条路径
  - `crawler` → 调用 `services/crawler/{crawler_class}.py`
  - `rss` → 调用 `services/rss_adapter.py`（基于 feedparser，v1 已有逻辑升级）
- `crawler_class`：仅对 `source_type=crawler` 有效，存类名字符串
  - 这样新增爬虫时只需 `config.yaml` 加项 + 一个 Crawler 类文件，无需改 dispatcher 代码
- `is_recommended=1` 的源不允许被删除（保护预设源）

### 4.3 news_articles（新闻 = 首页列表）

```sql
CREATE TABLE news_articles (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  source_id     INTEGER NOT NULL,
  url           TEXT NOT NULL,                   -- 原文 URL
  url_hash      TEXT NOT NULL UNIQUE,            -- SHA1(source_code + url)，去重主键
  title         TEXT NOT NULL,
  summary       TEXT,                            -- 首页列表抓到的摘要（200-500 字）
  cover_image   TEXT,
  author        TEXT,
  published_at  TEXT,                            -- ISO8601 UTC
  fetched_at    TEXT NOT NULL,                   -- 入库时间，用于清理
  position      INTEGER NOT NULL,                -- 在源列表中的原始序号（Top3 排序依据）
  FOREIGN KEY (source_id) REFERENCES news_sources(id) ON DELETE CASCADE
);

CREATE INDEX idx_articles_source      ON news_articles(source_id);
CREATE INDEX idx_articles_pub         ON news_articles(published_at);
CREATE INDEX idx_articles_source_pos  ON news_articles(source_id, position);
```

**关键说明**：

- `url_hash` = `SHA1("{source_code}|{url}")`，数据库唯一约束 + 业务层二次校验双保险
- `position` 是源页面内的原始序号（如 BBC 首页列表的第 5 条 = position=5）
  - 首页"每源 Top 3"按 `position ASC` 取前 3 条
  - 用户看到的"顺序"会与源站编辑排序一致（编辑们排过的顺序往往就是重要性排序）
- `summary` 长度为 200-500 字符之间，是详情页的主内容（**D + C 兜底里的 D**）

### 4.4 news_contents（详情正文，按需）

```sql
CREATE TABLE news_contents (
  news_id       INTEGER PRIMARY KEY,             -- = news_articles.id
  content_html  TEXT NOT NULL,                   -- 抓到的正文 HTML（去除 nav/aside/ad 等）
  content_text  TEXT,                            -- 纯文本备用
  fetched_at    TEXT NOT NULL,                   -- 抓取时间
  expires_at    TEXT NOT NULL,                   -- 过期时间（fetched_at + 24h）
  FOREIGN KEY (news_id) REFERENCES news_articles(id) ON DELETE CASCADE
);

CREATE INDEX idx_contents_expires ON news_contents(expires_at);
```

**为什么需要这张表**：
- 列表页只拿首页摘要（200-500 字），对绝大多数新闻够用
- 但有些新闻首页摘要太短（< 100 字），点进详情页看个寂寞
- 用户点进详情页时，**按需**爬原文 HTML 入库，缓存 24h（`D + C` 兜底里的 `C`）
- 24h 后下次访问再爬

## 五、爬虫层

### 5.1 抽象基类（`app/services/crawler/base.py`）

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Optional


@dataclass
class CrawledItem:
    """统一抓取结果"""
    url: str
    title: str
    summary: str                # 200-500 字
    cover_image: Optional[str] = None
    author: Optional[str] = None
    published_at: Optional[str] = None  # ISO8601 UTC
    position: int = 0           # 源页面内的顺序，1-based


@dataclass
class CrawlResult:
    source_code: str
    items: list[CrawledItem] = field(default_factory=list)
    error: Optional[str] = None


class BaseCrawler(ABC):
    """所有爬虫的基类。"""

    def __init__(self, source_config: dict, http_client: httpx.AsyncClient):
        self.source_config = source_config
        self.client = http_client

    @abstractmethod
    async def fetch_list(self, homepage_url: str) -> CrawlResult:
        """抓取首页/列表页，返回 CrawlResult。"""
        ...

    async def fetch_content(self, url: str) -> Optional[str]:
        """按需抓取详情页 HTML，子类可重写。"""
        try:
            resp = await self.client.get(url, follow_redirects=True)
            resp.raise_for_status()
            return self._extract_content_html(resp.text)
        except Exception as e:
            logger.warning(f"fetch_content failed for {url}: {e}")
            return None

    def _extract_content_html(self, raw_html: str) -> str:
        """默认实现：用通用规则提取正文。子类可重写以使用更精确的选择器。"""
        from bs4 import BeautifulSoup
        soup = BeautifulSoup(raw_html, "lxml")
        # 移除噪声
        for tag in soup(["script", "style", "nav", "header", "footer", "aside", "noscript"]):
            tag.decompose()
        # 优先 article / main / role=main
        article = (
            soup.find("article")
            or soup.find("main")
            or soup.find(attrs={"role": "main"})
            or soup.find(class_=re.compile(r"article|content|story", re.I))
        )
        return str(article) if article else str(soup.body) if soup.body else ""
```

### 5.2 4 个专用 Crawler

每个 Crawler 一个文件：

```
app/services/crawler/
├── bbc.py        class BBCCrawler(BaseCrawler)
├── cnn.py        class CNNCrawler(BaseCrawler)
├── aljazeera.py  class AlJazeeraCrawler(BaseCrawler)
└── ap.py         class APCrawler(BaseCrawler)
```

每个 Crawler 的职责：
1. 用 httpx 抓首页 HTML
2. 用 BeautifulSoup + 源专属选择器提取列表项
3. 每条生成一个 `CrawledItem`，`position` 为源列表中的序号
4. 重写 `_extract_content_html`（可选）以提高详情页正文提取精度

**BBC 主页参考选择器**（v1 已抓过，仅作为大纲）：

```python
class BBCCrawler(BaseCrawler):
    async def fetch_list(self, homepage_url: str) -> CrawlResult:
        result = CrawlResult(source_code="bbc")
        try:
            resp = await self.client.get(homepage_url, follow_redirects=True)
            resp.raise_for_status()
            soup = BeautifulSoup(resp.text, "lxml")

            # BBC 新版结构：data-testid="card"
            cards = soup.select('div[data-testid="card"], a[data-testid="card"]')
            for i, card in enumerate(cards[:50], start=1):
                title_el = card.select_one('h2, h3, [data-testid="card-title"]')
                link_el = card if card.name == "a" else card.select_one("a")
                summary_el = card.select_one('p, [data-testid="card-description"]')
                img_el = card.select_one('img')
                if not (title_el and link_el and link_el.get("href")):
                    continue
                url = urljoin(homepage_url, link_el["href"])
                # ... 构造 CrawledItem
                result.items.append(CrawledItem(
                    url=url,
                    title=title_el.get_text(strip=True),
                    summary=summary_el.get_text(strip=True) if summary_el else "",
                    cover_image=img_el.get("src") if img_el else None,
                    position=i,
                ))
        except Exception as e:
            result.error = f"BBC fetch failed: {e}"
        return result
```

> 注：实际选择器需根据抓取到的真实 HTML 调整。**实施时第一步是离线抓取每个源首页 HTML 样本，分析结构再写选择器**。

### 5.3 Reuters 降级：`reuters_rss.py`

实际上就是个简化版 RSS parser（v1 已有逻辑的薄包装）：

```python
class ReutersViaGoogleNewsRSS(BaseCrawler):
    """Reuters 抓不到 RSS，用 Google News 站内搜索 RSS 兜底。"""
    async def fetch_list(self, homepage_url: str) -> CrawlResult:
        rss_url = self.source_config["rss_url"]
        result = CrawlResult(source_code="reuters")
        try:
            import feedparser
            resp = await self.client.get(rss_url, follow_redirects=True)
            resp.raise_for_status()
            feed = feedparser.parse(resp.text)
            for i, entry in enumerate(feed.entries[:50], start=1):
                # 过滤：只保留确实指向 reuters.com 的条目
                if "reuters.com" not in entry.get("link", ""):
                    continue
                summary = self._strip_html(entry.get("summary", ""))
                result.items.append(CrawledItem(
                    url=entry["link"],
                    title=entry.get("title", ""),
                    summary=summary,
                    published_at=self._parse_date(entry),
                    position=i,

        except Exception as e:
```

```python
    """用于用户自定义 HTML 源。基于公开 meta 标签和常见语义标签。"""

    EXTRACT_RULES = {
        "title": [
            'meta[property="og:title"]@content',
            'meta[name="title"]@content',
            'meta[name="twitter:title"]@content',
            'h1',
        ],
        "summary": [
            'meta[property="og:description"]@content',
            'meta[name="description"]@content',
            'meta[name="twitter:description"]@content',
        ],
        "cover_image": [
            'meta[property="og:image"]@content',
            'meta[name="twitter:image"]@content',
            'article img@src',
        ],
        "list_item": [
            # 找列表项 - 常见选择器，命中即用
            'article',
            '.article, .post, .entry, .story, .news-item',
        ],
    }

    async def fetch_list(self, homepage_url: str) -> CrawlResult:
        result = CrawlResult(source_code=self.source_config["code"])
        try:
            resp = await self.client.get(homepage_url, follow_redirects=True)
            resp.raise_for_status()
            soup = BeautifulSoup(resp.text, "lxml")

            # 提取页面级 title/summary/image 作为唯一一条
            title = self._first_match(soup, self.EXTRACT_RULES["title"])
            summary = self._first_match(soup, self.EXTRACT_RULES["summary"])
            cover = self._first_match(soup, self.EXTRACT_RULES["cover_image"])
            if title:
                result.items.append(CrawledItem(
                    url=homepage_url,
                    title=title,
                    summary=summary or "",
                    cover_image=cover,
                    position=1,
                ))
        except Exception as e:
            result.error = f"Generic HTML fetch failed: {e}"
        return result
```

- 大量新闻站点是 SPA，单 HTML 抓不到列表 —— **通用爬虫对自定义源只保证单条信息，不保证列表**
- 用户预期管理：**添加自定义 HTML 源后看到一条该站首页的新闻**

```python
class RSSSourceAdapter:
    def __init__(self, timeout: int, proxy: str, proxy_enabled: bool):
        self.timeout = timeout
        self.proxy = proxy
        self.proxy_enabled = proxy_enabled

    async def fetch(self, source_code: str, source_name: str, rss_url: str, max_items: int = 50) -> CrawlResult:
        result = CrawlResult(source_code=source_code)
        try:
            client_kwargs = {"timeout": self.timeout}
            if self.proxy_enabled and self.proxy:
                client_kwargs["proxy"] = self.proxy
            async with httpx.AsyncClient(**client_kwargs) as client:
                resp = await client.get(rss_url, follow_redirects=True)
                resp.raise_for_status()
            import feedparser
            feed = feedparser.parse(resp.text)
            if feed.bozo and not feed.entries:
                result.error = f"RSS parse failed: {feed.bozo_exception}"
                return result
            for i, entry in enumerate(feed.entries[:max_items], start=1):
                title = entry.get("title", "").strip()
                if not title:
                    continue
                summary = self._strip_html(entry.get("summary", "") or entry.get("description", ""))[:1000]
                result.items.append(CrawledItem(
                    url=entry.get("link", ""),
                    title=title,
                    summary=summary,
                    cover_image=self._extract_image(entry),
                    author=entry.get("author", ""),
                    published_at=self._parse_date(entry),
                    position=i,
                ))
        except Exception as e:
            result.error = f"RSS fetch failed: {e}"
        return result
```

## 六、调度器（分时段）

### 6.1 设计

v1 的 APScheduler 用单一 cron，本版本改为**基于 asyncio 的循环调度器**（更灵活）：

```python
# app/tasks/scheduler.py
class TimeBasedScheduler:
    """
    根据 config.yaml 的 schedule 段，在指定时间段内每 N 分钟触发一次任务。
    替代 v1 的单一 cron。
    """
    def __init__(self, config: AppConfig):
        self.config = config
        self.schedule = config.fetch.schedule  # [{start,end,interval_minutes}, ...]
        self.task = None

    async def start(self):
        self.task = asyncio.create_task(self._loop())

    async def _loop(self):
        while True:
            now = datetime.utcnow()
            interval = self._interval_for(now.time())
            # 随机抖动，避免规律请求
            jitter = random.uniform(0, self.config.fetch.jitter_seconds)
            await asyncio.sleep(interval * 60 + jitter)
            await fetch_task.run()

    def _interval_for(self, t: time.time) -> int:
        """返回当前时间对应的调度间隔（分钟）。"""
        for slot in self.schedule:
            s = time.fromisoformat(slot["start"])
            e = time.fromisoformat(slot["end"])
            if s <= e:
                in_slot = s <= t < e
            else:  # 跨天，如 23:00 - 06:00
                in_slot = t >= s or t < e
            if in_slot:
                return slot["interval_minutes"]
        return 60  # 兜底
```

### 6.2 时段说明

| 时段 | 时间 | 间隔 | 理由 |
|------|------|------|------|
| 早高峰 | 06:00-10:00 | **30 分钟** | 用户起床看新闻、晨间新闻密集 |
| 日间 | 10:00-18:00 | **60 分钟** | 用户在工作，新闻密度低 |
| 晚高峰 | 18:00-23:00 | **30 分钟** | 用户下班看新闻、晚间新闻密集 |
| 凌晨 | 23:00-06:00 | **180 分钟** | 低活跃，省代理流量，省源站压力 |

### 6.3 与 v1 差异

- v1 的 cron 路径被完全替换为新 scheduler
- 仍然可以手动触发：`POST /api/v2/trigger/fetch`
- Cleanup 任务保留 cron 风格：`0 5 * * *`

```python
async def get_news_detail(news_id: int, db: Session):
    article = db.query(NewsArticle).filter_by(id=news_id).first()
    if not article:
        raise NotFoundError("News not found")

    source = article.source
    summary = article.summary or ""
    content_html = None
    content_source = "homepage"
    fetched_at = None

    # 1) 查 news_contents 缓存
    cached = db.query(NewsContent).filter_by(news_id=news_id).first()
    if cached and cached.expires_at > now_str():
        content_html = cached.content_html
        content_source = "fetched"
        fetched_at = cached.fetched_at
        return _build_response(article, source, summary, content_html, content_source, fetched_at)

    # 2) 判断是否需要按需爬
    # 阈值：summary < 100 字且 content_fetcher 配置启用且源支持爬详情
    if len(summary) >= 100 or not content_fetcher.enabled:
        return _build_response(article, source, summary, None, "homepage", None)

    # 3) 按需爬详情页
    crawler = source_dispatcher.get_crawler(source)  # 用专门的爬虫类
    full_html = await crawler.fetch_content(article.url)
    if full_html:
        # 缓存
        content = NewsContent(
            news_id=news_id,
            content_html=full_html,
            fetched_at=now_str(),
            expires_at=(now + timedelta(hours=24)).strftime("%Y-%m-%dT%H:%M:%SZ"),
        )
        db.merge(content)
        db.commit()
        content_html = full_html
        content_source = "fetched"
        fetched_at = content.fetched_at

    return _build_response(article, source, summary, content_html, content_source, fetched_at)
```

### 8.1 抓取流（每 30-180 分钟自动 / 手动触发）

```
                  ┌─────────────────────────────────┐
                  │  fetch_task.run()               │
                  │  (scheduler / trigger)          │
                  └────────────┬────────────────────┘
                               ↓
                  ┌─────────────────────────────────┐
                  │  source_dispatcher.dispatch(s)  │
                  │  根据 source_type 分派          │
                  └────────────┬────────────────────┘
                               ↓
       ┌───────────────────────┼───────────────────────┐
       ↓ crawler              ↓ crawler               ↓ rss
   ┌──────────────┐      ┌──────────────┐       ┌──────────────┐
   │ BBCCrawler   │      │ APCrawler    │  ...  │ RSSAdapter   │
   │ CNNCrawler   │      │ AlJazeera    │       │ ReutersRSS   │
   └──────┬───────┘      └──────┬───────┘       └──────┬───────┘
          │                    │                      │
          └────────────────────┼──────────────────────┘
                               ↓
                  ┌─────────────────────────────────┐
                  │  for each CrawledItem:          │
                  │   compute url_hash              │
                  │   check existing by url_hash    │
                  │   apply max_age_hours filter    │
                  │   bulk insert with ON CONFLICT  │
                  └────────────┬────────────────────┘
                               ↓
                  ┌─────────────────────────────────┐
                  │  news_articles (URL Hash Unique)│
                  └─────────────────────────────────┘
```

### 8.2 用户读首页

```
Home.js  ─── GET /api/v2/home ───►  home.router
                                       │

                            source_id IN (enabled sources)
                            AND published_at >= now - home_window_hours
```

### 8.3 用户进详情页

```
Detail.js ─── GET /api/v2/news/{id} ───►  news.router
                                            │
                       1. fetch article + source
                       2. fetch summary (article.summary)

                          ├─ HIT  → return content_html from cache
                          └─ MISS → if summary 太短(< 100字) →

                                       写入 news_contents (TTL 24h)
                                            │
                                            └────► JSON { ..., content_html, content_source }
```

```
sources.js ─── POST /api/v2/sources/custom ──► sources.router
```
